# [멀티스레드 기반 로그인 서버]

## 1. 개요 (Overview)
- 한 문장 요약 : 자체 제작 라이브러리 기반 멀티스레드 로그인 서버
- 주요 기능 : Redis 기반 세션 키 저장, MySQL 기반 유저 정보 조회
- 핵심 기술 스택 : C++ 17, Redis, MySQL
- [서버 구조 및 프로토콜](./Architecture.md)

## 2. 성능 목표 (Performance Goals)
   ### 2.1 타겟 지표 (부하 테스트, 10k 접속)
       - 지표 : (기준치) / (달성치)
       - 레이턴시  : < 100ms / ms
       - 처리량    : 1000 TPS / TPS
       - CPU 사용률: < 10% / %
       - 메모리    : < 200MB / MB

   ### 2.2 목표 설정 근거
       - 레이턴시는 인간이 즉시 반응한다고 느끼는 속도의 마지노선인 100ms로 설정
       - MMORPG 기준 10,000명의 동시 접속을 기준으로 초당 1,000번의 로그인 처리면 충분하다고 판단
       - CPU 사용률의 경우 다른 컨텐츠 서버 고려 10%만 사용을 고려
       - 메모리의 경우 세션 별 객체 데이터 크기(약 8kb) * 5,000 + 직렬화 버퍼(550byte) * 10,000로 가정, 추가로 기타 메모리(150MB)로 상정
       > 40MB + 5MB + 150MB + @ = 200MB

## 3. 전체 시스템 성능(Overall Performance)
   ### 3.0 시나리오 (Scenario)
      - 2,500명 단위로 증가 시키며, 지속적인 로그인 시도

   ### 3.1 처리량 (Throughput)
      | 동시 접속  | 패킷 처리량     | TPS(Send) |
      | 2,500     | 50k pps       | 45k       |
      | 5,000     | 50k pps       | 45k       |
      | 7,500     | 185k pps      | 175k      |
      | 10,000    | 400k pps      | 370k      |
   
   ### 3.2 레이턴시 (Latency)
      | 동시 접속 | 평균 |
      | 2,500   | 3ms  |
      | 5,000   | 3ms  |
      | 7,500   | 3ms  |
      | 10,000  | 6ms  |
   
   ### 3.3 리소스 사용량
      | 동시 접속 | CPU (%) | 메모리 (MB) | 네트워크 (Mbps) |
      | 2,500    | 2      | 225        | 85             |
      | 5,000    | 2      | 225        | 85             |
      | 7,500    | 2      | 225        | 85             |
      | 10,000   | 6      | 231        | 320            |
