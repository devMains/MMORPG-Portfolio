## 2. 성능 목표 (Performance Goals)

### 2.1 타겟 지표 (부하 테스트, 10K 접속 기준)
| 지표 | 목표 기준치 | 🏆 최종 달성치 |
| :--- | :--- | :--- |
| **동시 접속 (CCU)** | 10,000 명 | **10,000 명** |
| **레이턴시 (Latency)** | < 100 ms | **65 ms** |
| **처리량 (Throughput)** | 1M pps | **1.5M pps** |
| **CPU 사용률** | < 35% | **30%** |
| **메모리 사용량** | < 500 MB | **250 MB** |

### 2.2 목표 설정 근거
*   **레이턴시 (100ms):** 인간이 지연을 체감하지 않고 즉각적으로 반응한다고 느끼는 한계선을 100ms로 상정했습니다.
*   **처리량 (1M pps):** 채팅 서버 특성상 1명의 유저가 1초에 약 100개의 패킷(브로드캐스트 포함)을 처리한다면 상당한 과부하 상태이므로, 1만 명 기준 1M pps(1,000,000)를 목표 상한선으로 잡았습니다.
*   **리소스 한계선:** 채팅 서버 외에 다른 콘텐츠 처리 시스템과 서버 리소스를 분배해야 하므로 CPU는 최대 35%까지만 점유하도록 제한했습니다.
*   **메모리 계산식:** 
    *   (세션 객체 8KB * 10,000명) + (직렬화 버퍼 550Bytes * 100,000개) + (기타 OS/스택 할당 150MB) ≈ **약 285MB**
    *   극심한 부하 상황에서 버퍼 풀(Pool)과 락프리 큐 노드가 팽창할 가능성을 고려하여 넉넉하게 500MB를 최대 한계치로 지정했습니다.

## 5. 기술적 도전과 문제 해결 (Troubleshooting)

**[문제 1] 생산자/소비자 속도 불균형으로 인한 큐 메모리 폭증 (Backpressure 부재)**
*   **현상:** 과부하 환경에서 메모리 풀(직렬화 버퍼, 락프리 큐 노드)의 사용량이 무한정 늘어나는 메모리 폭증 현상을 발견했습니다.
*   **원인:** 채팅 1개의 메시지가 주변 유저 수십 명에게 복제되어 전송되는 구조상, **콘텐츠 스레드(생산자)가 메시지를 큐에 밀어 넣는 속도가 네트워크 I/O 스레드(소비자)가 실제 소켓으로 `WSASend`를 호출하여 큐를 비우는 속도보다 훨씬 빨라졌기 때문**입니다.
*   **해결:** 네트워크 송신 스레드의 개수를 콘텐츠 생산 스레드에 맞춰 적절히 늘려 병목을 완화했습니다. 
*   **결과(Trade-off):** I/O 스레드를 늘리면서 과부하 시 전체 CPU 사용률이 100%에 도달하게 되었고, 이로 인해 콘텐츠 스레드의 속도 자체가 강제로 제어(Throttling)되어 큐가 무한히 쌓이는 증상이 사라졌습니다. 메모리 폭증(Crash 발생)보다는 성능 저하(지연 발생)가 서버 운영상 더 안전한 실패(Graceful Degradation) 방식이라고 판단했습니다.

**[문제 2] 동적 자원 브로드캐스팅 시의 패킷 유실 및 중복 (Data Inconsistency)**
*   **현상:** 유저가 특정 섹터에서 다른 섹터로 이동하는 찰나의 순간에, 주변 섹터로 전파되는 메시지를 아예 받지 못하거나(유실) 두 번 받는(중복) 데이터 불일치 문제가 발생했습니다.
*   **원인:** 3x3 범위의 섹터에 메시지를 뿌릴 때, 9개의 섹터를 '순차적으로' 개별 락을 걸고 전송했기 때문입니다. 락이 풀린 섹터와 락이 아직 걸리지 않은 섹터 사이를 유저가 이동하면서 사각지대가 생겼습니다.
*   **해결:** 메시지 전파 시 대상이 되는 **주변 9개 섹터의 락(SRWLock)을 동시에 모두 획득(Multi-Lock)한 뒤 전송**하도록 아키텍처를 변경했습니다. 단, 여러 스레드가 동시에 9개 섹터의 락을 잡으려 할 때 발생하는 **데드락(Deadlock)을 회피하기 위해, 항상 일정한 순서(예: 섹터 인덱스 오름차순)로만 락을 획득하도록 정렬(Sorting) 규칙을 강제**했습니다.
*   **결과:** 섹터 이동 시에도 메시지 정합성이 완벽하게 보장되었습니다.
