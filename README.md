# MMORPG Server Portfolio

**C++로 구현한 게임 서버 프로그래머 포트폴리오**

자체 제작 네트워크 라이브러리 기반의 고성능 MMORPG 서버 시스템

</div>

## 프로젝트 개요

MMORPG 서버 프로그래머 직무 지원을 위한 포트폴리오입니다.

네트워크 라이브러리를 직접 설계 및 구현하여, 실제 게임 서버(로그인/채팅)에 적용한 프로젝트입니다.
동시성 처리, 성능 최적화, 확장성에 중점을 두고 개발하였습니다.

## 프로젝트 구조

### 1. 네트워크 라이브러리

> **핵심 컴포넌트**

- 직렬화 버퍼: 동일 메시지 재사용으로 인한 메모리 절약
- 수신용 링버퍼: 미완성 패킷을 위한 저장 공간
- 송신용 락프리큐: CAS 기반, 직렬화 버퍼의 주소를 WSASend에 즉시 이용
- TLS 메모리풀: 스레드별 독립 풀, 스레드 간 경합 최소화

  **[컴포넌트 설명](1.%20NetworkLibrary/Components)**

> **핵심 기능**

- Ip, Port에 기반한 WhiteIp 시스템 구축 가능
- 완성 패킷 단위 전달
- 세션 키 기반 세션 관리, 패킷 전송
- 세션 접속, 세션 해제 알림

  **[상세 문서](1.%20NetworkLibrary/README.md)**

### 2. 로그인 서버

> **핵심 기능**

- 세션 키 기반 로그인 (퍼블리셔 DB 접근 가정)
- 중복 로그인 방지
- 세션 키 Redis 저장

  **[상세 문서](2.%20Servers/LoginServer/README.md)**

### 3. 채팅 서버

> **핵심 기능**

- 호모 지니어스 기반 멀티 스레드 설계로 인한 확장성 고려
- Redis 조회를 통한 로그인 인증
- 섹터 기반 채팅 구현, 주위 섹터 채팅 전달

  **[상세 문서](2.%20Servers/ChatServer/README.md)**
